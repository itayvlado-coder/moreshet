## Setup — Three Steps

### Step 1 — Create your OS folder

1. Create a new folder anywhere on your Mac. Name it something like **YourName-OS**.
2. Open the zip file you received.
3. Open the extracted folder called "Spark AI System v0."
4. Select all the files inside it (Cmd+A) and copy them.
5. Paste into your YourName-OS folder.

Your folder should now contain: `CLAUDE.md`, `Core/`, `Memory/`, `Agents/`, `Brain/`, `GTM/`, `Tools/`

### Step 2 — Choose a name for your COO

Before opening Claude Code, decide on a name for your AI COO. This is the name you will type every day to start your session. Any name that feels right to you.

Write it down. You will use it in Step 3.

### Step 3 — Your first session

1. Open Claude Code (`claude.ai/code`)
2. Sign in with your Claude account
3. Click **Open folder** and select your YourName-OS folder
4. Type: `/setup`

The first thing the system asks is: "What name do you want to give me?" Give your COO a name. From there, they guide you through everything — ask you questions, fill all your Core files, write your CLAUDE.md, and connect you to GitHub. You just answer. They build.

Once setup is complete, every future session starts with: `hi [your COO name]`

**Full setup guide:** `Tools/00-Guide/spark-os-guide.md`

## The Architecture

| Folder / File | What It Holds |
|---------------|---------------|
| `CLAUDE.md` | The constitution. Claude reads this first, every session. |
| `Core/` | Who you are: brief, voice DNA, ICP. |
| `Memory/` | What you remember: essentials, learning log, decisions, feedback. |
| `Agents/` | Your AI team. Each agent is a file. |
| `Brain/` | Your knowledge vault: inbox, research, templates. |
| `GTM/` | Go-to-market: content, channels, customers. |
| `Tools/` | Skills, workflows, and this guide. |

---

## The Loop

At the end of every meaningful session, tell your COO: **"Close the loop."**

They will update:
- `Memory/learning-log.md` — what was learned
- `Memory/decisions.md` — what was decided
- `Memory/feedback.md` — feedback and signals from the outside world
- `Memory/essentials.md` — if the current state changed

Then they commit and push everything to GitHub. The system is backed up. The session is closed.

This is how the system gets smarter over time. Do not skip it.
