# מצגת חטיבת גבעתי לאוגדה 162: קובץ מקור

המצגת נבנית כדף HTML ומודפסת ל-PDF לרוחב (1600x900) דרך Google Chrome במצב headless.

## הקבצים

| קובץ | מה יש בו |
|------|----------|
| `deck_data.py` | פרטי כל מועמד: דרגה, שם, תפקיד, כוח, רמת המלצה, זירה עיקרית וזירות משניות (`CAND`). גם הנופלים (`FALLEN`), סדר הדרגות, נקודות המרשם והזירות. |
| `cards.jsonl` | שורה לכל מועמד, לפי המספר שלו ב-`CAND`: `lead` (משפט "למה הוא מועמד"), `hi` (2-3 דברים שבלטו), `stats` (מספרים), `arena` (שורת הזירות שמתחת למרשם). |
| `build_deck.py` | בונה את כל השקפים. הטקסטים של שקפי הזירה (`ARENA_TXT`), סיפורי הגדודים (`BATT`), ציר הזמנים (`GANTT`), סד"כ 6.10 (`s_picture`), פיקוד ושליטה (`s_c2`), תחקירים, יחידתי וסיום. |
| `deck.css` | העיצוב. |
| `assets/` | הגופנים (Heebo, Frank Ruhl Libre) והלוגואים. |
| `shot.py` | צילום מסך של שקף בודד לבדיקה: `python3 shot.py 27` יוצר `preview/slide_27.png`. |

## בנייה

דורש Mac עם Google Chrome מותקן ב-`/Applications`, ו-Python 3. אין חבילות נוספות.

```
python3 build_deck.py             # בונה את ה-PDF ובודק גלישת טקסט
python3 build_deck.py --preview   # גם גיליונות תצוגה מקדימה בתיקייה preview/
```

אחרי הבנייה הסקריפט מדפיס `overflow: none` אם אין טקסט שגולש מהשקף. אחרת הוא מפרט את מספרי השקפים.

## איך משנים

- **מועמד חדש:** להוסיף שורה ל-`CAND` ב-`deck_data.py` ושורה עם אותו מספר ב-`cards.jsonl`.
- **סדר המועמדים בכל זירה:** הפונקציה `cands_in` ב-`build_deck.py`. כרגע לפי דרגה. כדי לסדר לפי מקום בדירוג, אפשר למיין לפי המספר.
- **נופל:** להוסיף את המספר ל-`FALLEN` עם שורת התפקיד, המקום והתאריך. היא מופיעה בצד הסגול של השקף.
- **שקף חדש:** לכתוב פונקציה `s_...()` שמחזירה `slide(...)` ולהוסיף אותה ל-`build_slides()`.

המספרים ב-`CAND` הם המקומות בדירוג החטיבתי מ-2.11 (62 שורות). הם משמשים רק כמפתח, ולא מוצגים במצגת.
