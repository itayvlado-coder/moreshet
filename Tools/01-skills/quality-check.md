# Skill: Quality Check

*Final review of any content before it is approved for publishing.*

---

## When to Use

After a post (or any piece of content) is written, before the CEO approves it. This is the last gate.

This skill is Step 4 of the `/content` workflow.

**Standalone trigger:** Tell your COO: "Quality check this post: [paste content]."

---

## What This Skill Does

Reviews the content against four criteria and returns a clear verdict.

---

## The Four Checks

### 1. Voice Check
Read `Core/voice-dna.md`. Ask: does this sound like us?
- Does it match the tone attributes?
- Are there any words or phrases in the "avoid" list?
- Would the CEO be comfortable saying this out loud to a room of their ideal customers?

### 2. Mechanics Check
- Em dashes — scan character by character. Zero tolerance.
- Passive voice — flag every instance
- Filler words — "leverage," "synergy," "optimize," "it's worth noting," "in today's world"
- First line — does it earn the scroll? Would you stop and read?
- Word count — is it within range? (LinkedIn: 150-250 words recommended)

### 3. Substance Check
- Is there a real, specific insight? Or is it a vague observation anyone could write?
- Are claims backed by something real (example, data, personal experience)?
- Is there anything factually uncertain? Flag it.

### 4. Audience Check
Read `Core/icp-profile.md`. Ask: would the ideal customer read this and think "this is for me"?
- Does it speak to a real problem they have?
- Does it avoid talking down to them?
- Does the ending land for someone at their stage?

---

## Output Format

```
QUALITY CHECK — [Post title/topic]

Voice: PASS / NEEDS WORK — [note if needed]
Mechanics: PASS / NEEDS WORK — [specific issues]
Substance: PASS / NEEDS WORK — [note if needed]
Audience: PASS / NEEDS WORK — [note if needed]

VERDICT: APPROVED / REVISE

[If REVISE: list specific changes needed, ranked by importance]
```

---

## Rules

- Be honest. A passing review of a weak post helps no one.
- Do not rewrite the post in this step — flag issues and send back for revision.
- APPROVED means it is ready to publish. Not "good enough." Ready.
