# Skill: Content Repurpose

*Turn one piece of content into multiple formats across channels.*

---

## When to Use

You wrote a newsletter, a long post, a talk, or a document. You want to get more out of it without starting from scratch.

**Trigger:** Tell your COO or Copywriter: "Repurpose [content title] for [target channels]."

---

## What This Skill Produces

Given one source piece, it creates:

- **LinkedIn post** — 150-250 words, conversational, one key insight from the source
- **Short-form hook** — 1-3 sentences, shareable standalone observation
- **Email teaser** — 2-3 sentences to use as a newsletter intro or follow-up

Add more output formats as you need them.

---

## How to Run It

1. Paste the source content (or give the file path)
2. Tell the agent which channels you want
3. Specify the voice: formal or casual, which language, any audience notes
4. Review, edit, approve

---

## Rules

- Always read `Core/voice-dna.md` before writing
- Never copy-paste from source — paraphrase and distill
- Each output should stand alone; do not assume the reader saw the original
- Run through Proximus (your Gatekeeper) before publishing anywhere
