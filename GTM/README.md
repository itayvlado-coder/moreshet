# GTM — Go to Market

Everything related to how you reach and serve customers.

---

## Structure

Add subfolders as you activate channels:

```
GTM/
├── Newsletter/     ← When you launch a newsletter
├── LinkedIn/       ← LinkedIn content system
├── B2B/            ← Outbound, partnerships, enterprise
├── B2C/            ← Inbound, consumer, community
└── Customers/      ← One folder per customer
```

---

## Start Simple

You do not need all of this on day one.

Start with one channel — the one where your customers already are. Build that well. Add more when the first one is working.

Tell your COO: "Help me set up our [newsletter / LinkedIn / outbound] system."
