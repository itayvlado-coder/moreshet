# Agents — Your AI Team

Each agent is a file. Each file is a role. When you invoke an agent, Claude reads their file and becomes that person for the session.

---

## Your Team

| Agent | File | Role |
|-------|------|------|
| Steven | `YOUR-COO-NAME-COO.md` | COO — runs the system, builds the team, closes the loop |

*This table gets updated as you build new agents. Your COO maintains it.*

---

## How to Invoke an Agent

Type: `hi [name]`

That is it. Claude reads the agent's file and becomes that role. They stay active until the session ends.

---

## Day One

You do not need to build any agents today. Your COO handles everything in the first session. Once the system is running and you have recurring needs that require a specialist — a copywriter, a researcher, a strategist — you ask your COO to build them.

Tell your COO: "I need an agent who [does X]." They handle the rest.

---

## The Rule

One agent at a time. Invoke who you need. The rest wait.
